# AI Image Studio Pro

Professional AI image editing application built with Python and Streamlit.

## Features

- AI background removal
- Edge and hair refinement
- Brightness, contrast and saturation
- Sharpness and clarity
- Blur
- Solid background
- Gradient background
- Custom background image
- Background blur
- Subject shadow
- Crop
- Rotate
- Flip
- Auto enhance
- HD upscaling
- PNG, JPG and WebP export
- Batch image processing
- ZIP download
- Undo and reset

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
